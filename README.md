# 团团和它的毛茸茸朋友

面向小学三年级儿童的英语学习与陪伴冒险微信小程序。团团是孩子的智能陪伴伙伴。Sprint 2 已完成第一章《消失的星星饼干》的本地试玩闭环，其他章节仍在规划中。

## 项目目标

- 将小学英语词汇、句型和听说练习融入宠物照料、剧情探索和短小游戏。
- 以温和、可重复、低挫败感的互动建立学习习惯。
- 预留教材 PDF 内容整理/导入接口，以及微信云开发能力。
- 保护儿童隐私，默认最少化收集数据；不设计社交、广告或付费诱导作为核心环节。

## 开发准备

使用微信开发者工具“导入项目”，选择**包含 `project.config.json` 的仓库根目录**；配置已将 `miniprogram/` 指为源码目录。配置中的 `touristappid` 是体验占位值，真机调试与上传时请使用自己有权限的小程序 AppID，并把个人配置保存在被忽略的 `project.private.config.json`。项目不依赖 npm 包或云环境。

导入后点击“编译”，首页应显示树屋、团团、今日任务和“开始冒险”。点击“开始冒险”进入五幕故事。第三幕会引导到“听音找图片”，听三条单词录音并选图，返回故事后继续至第五幕；完成后获得小游戏 2 颗星、章节 5 颗星，并解锁米米。首页“伙伴”可查看角色，“单词卡”可查看六个独立测试词。关闭并重新打开模拟器后，章节、小游戏回合、奖励与学习记录应保留。可在开发者工具 Storage 面板查看 `fluffy-town:local:v4`；旧版 v1/v2/v3 会在首次读取时迁移，旧键暂时保留。旧版单幕测试章节的进度会单独重置，以便试玩新版五幕章节。

当前只制作了第一章与一款小游戏。音频为已标记 CC0 的公开录音，图片为原创占位图；尚未接入真实教材、PDF 导入、家长端或云同步。音频播放和页面布局需在微信开发者工具及真机复核。

## Alpha Demo运行说明

1. 安装并打开微信开发者工具，选择“导入项目”。项目目录选择**仓库根目录**（即包含 `project.config.json` 的目录），不要选 `miniprogram/` 子目录。
2. 项目类型选择“小程序”。本地模拟器可先使用配置中的 `touristappid`；若开发者工具要求登录或有效 AppID，请换成自己有权限的小程序 AppID，并将本机设置保存在 `project.private.config.json`。项目无需安装 npm 依赖，也无需开通云开发。
3. 导入后点击“编译”。`project.config.json` 指定 `miniprogram/` 为源码根目录，`app.json` 首项 `pages/home/home` 是启动页。模拟器应先显示树屋、团团、今日任务与“开始冒险”。
4. 点击“开始冒险”进入第一章，逐幕点击“继续故事”；在“寻找线索”处进入听音找图。每轮点击“播放单词”，再选对应图片。若设备声音不可用，页面会显示目标单词供继续体验。
5. 完成三轮后点“继续故事”，继续至章节结束。此时可看到小游戏奖励 2 颗星、章节奖励 5 颗星，共 7 颗星；米米解锁。可从结束页打开“伙伴”，或返回树屋进入“单词卡”查看 6 个独立测试词并记录“我认识了”。
6. 在开发者工具“调试器 → Storage”查看本地键 `fluffy-town:local:v4`。再次编译后进度应保留。若要从头检查完整流程，可在调试器中清除该键后重新编译；这会删除当前模拟器里的 Alpha 试玩进度。

**当前可体验**：首页团团点击互动、第一章五幕、三轮听音找图、星星与米米解锁、伙伴页和六张测试单词卡。页面入口为 `home → story → games → story → pets/home`；`learn` 从 `home` 进入。

**已知缺失**：只有第一章和一款小游戏；树屋与角色为原生样式或占位图；真实教材 Unit 1 的解析与映射仍待人工审核，尚未接入试玩内容；PDF 自动解析、更多年级、家长端、云同步及正式剧情均未实现。真机音频和布局仍需实际设备复核。

## 约定

- 内容数据与页面逻辑分离，教材内容需经人工校对后发布。
- 题目、关卡和剧情使用稳定 ID 与版本号，便于更新和迁移。
- 学习记录只保存实现体验所必需的数据；云端同步采用显式配置和可降级设计。
- 具体教材范围、合规要求、视觉稿与云环境在进入开发前确认。
