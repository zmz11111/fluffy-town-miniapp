# 团团和它的毛茸茸朋友

面向小学三年级儿童的英语学习与宠物冒险微信小程序。当前仓库阶段为**项目初始化与设计**：本文档定义需求、架构、数据和开发路径，不包含完整功能实现。

## 项目目标

- 将小学英语词汇、句型和听说练习融入宠物照料、剧情探索和短小游戏。
- 以温和、可重复、低挫败感的互动建立学习习惯。
- 预留教材 PDF 内容整理/导入接口，以及微信云开发能力。
- 保护儿童隐私，默认最少化收集数据；不设计社交、广告或付费诱导作为核心环节。

## 开发准备

Sprint 1 已建立原生微信小程序基础版本。使用微信开发者工具“导入项目”，选择**包含 `project.config.json` 的仓库根目录**；配置已将 `miniprogram/` 指为源码目录。配置中的 `touristappid` 是体验占位值，正式调试与上传时请在开发者工具中使用自己有权限的小程序 AppID，并把个人配置保存在被忽略的 `project.private.config.json`。项目不依赖 npm 包或云环境。

导入后点击“编译”，首页应显示树屋、团团、今日任务和“开始冒险”。点击团团会增加本地互动次数；点击“开始冒险”可查看 5 个示例词，选择“我认识了”后返回首页，任务进度会更新。关闭并重新打开模拟器后，互动次数与学习进度应保留。可在开发者工具的 Storage 面板查看 `fluffy-town:local:v1`。

这只是基础框架和记录演示，暂未实现完整游戏、真实教材、音频或云同步。

## 约定

- 内容数据与页面逻辑分离，教材内容需经人工校对后发布。
- 题目、关卡和剧情使用稳定 ID 与版本号，便于更新和迁移。
- 学习记录只保存实现体验所必需的数据；云端同步采用显式配置和可降级设计。
- 具体教材范围、合规要求、视觉稿与云环境在进入开发前确认。
