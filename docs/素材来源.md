# Sprint 2 素材来源

- `miniprogram/assets/pictures/` 下的猫、狗、饼干、星星 PNG 为本项目制作的原创几何占位图。
- `miniprogram/assets/audio/` 下六个英语单词 WAV 来自 Wikimedia Commons 的 Lingua Libre 录音，录音者与上传者 Wodencafe，文件页面均标为 **CC0 1.0**。为减小小程序包体积，本项目将原始 48 kHz 单声道 WAV 降采样为 16 kHz，未改动朗读内容。授权条款：https://creativecommons.org/publicdomain/zero/1.0/

## Sprint 4-B 视觉占位图

- `miniprogram/assets/characters/tuantuan/` 下四张表情 PNG、`characters/mimi/` 下头像 PNG，以及 `scenes/treehouse/` 下树屋 JPEG，均为本项目在 Sprint 4-B 绘制的原创几何占位图。它们不使用第三方角色、美术素材或教材插图。
- 这些图片只用于页面展示和资源接口联调；正式原画交付时须逐张记录作者、使用权、版本和审核人，并依 [视觉设计系统](VISUAL_DESIGN.md) 复核。
