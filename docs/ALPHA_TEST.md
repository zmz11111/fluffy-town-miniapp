# Alpha Demo 体验与测试记录（Sprint 4-C）

## 当前体验流程

1. 第一次打开首页，团团以简短对白欢迎孩子；点“好呀，一起看看”后，欢迎卡在当前设备只出现一次。首页继续显示团团的主动对白、示例词卡进度、第一章状态与下一步提示。
2. 点“开始冒险”进入第一章《消失的星星饼干》。故事页显示当前场景、角色头像、线索任务状态和下一步提示。
3. 到达寻找线索场景后，点“继续故事”进入听音找图。每轮显示线索进度；选错可重听，选对由团团鼓励。完成三轮后显示已获得的 2 颗星星。
4. 点“继续故事”回到第一章，完成后展示线索奖励 2 星、章节奖励 5 星及米米加入。首页与伙伴页可查看完成后的状态。

欢迎标记仅控制界面展示；章节、小游戏、奖励仍由原有业务管理器保存。教材内容与个人进度以稳定 ID 分离，后续接入不同教材、年级及家长端时可继续使用同一状态边界。

## 已知问题与范围

- 欢迎状态保存在当前设备本地，清除小程序数据或换设备后会再次出现；当前没有账户同步及家长端进度汇总。
- 任务名称“今日任务”仍展示六个示例词卡的累计进度，尚未按自然日重置。
- 第一章完成后再次进入直接显示完成卡片，当前不提供从头重播剧情的入口。
- 音频失败时可显示英文词作为退路；真实设备的音量、蓝牙、静音及弱网情况仍需人工验证。
- 角色与场景仍为占位资源；正式美术与真实教材内容尚未接入。欢迎和对白仅用项目原创文字。

## 测试计划

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 首次欢迎 | 清除本地数据后打开首页，关闭欢迎卡，再返回首页 | 首次看到欢迎卡；之后团团继续主动引导，欢迎卡不重复出现 |
| 中途返回 | 故事或小游戏进行到一半返回首页，再进入 | 首页显示当前任务方向，故事和小游戏从原有进度继续 |
| 答错与答对 | 先选错图，再选正确图片 | 答错保留回合并鼓励重听；答对推进线索并显示伙伴鼓励 |
| 奖励闭环 | 完成三轮，回到故事走完第一章 | 先见 2 星，再见章节 5 星与米米解锁；总星数为 7 |
| 重复进入 | 完成后再次进入小游戏和故事 | 奖励不重复增加，完成状态保持一致 |
| 音频或图片异常 | 在开发者工具模拟加载失败，并在真实设备检查 | 保留可读的文字或图形退路，不阻断剧情推进 |
| 儿童可用性 | 用小屏真机请三年级孩子独立体验，记录卡点 | 能找到下一步、理解任务状态和奖励；根据观察调整文案与触控区 |

开发者工具验证：导入仓库根目录，确认 `miniprogram` 为小程序目录，编译后按上表手动走查。真实设备、儿童可用性和家长观察尚待 Alpha 试玩验证。
