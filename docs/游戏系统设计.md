# 游戏系统设计

## 1. 体验循环

```text
选择短学习目标 → 学习词汇/句型 → 完成练习并获得提示反馈
       → 帮助团团/伙伴或推进剧情 → 解锁新内容 → 间隔复习
```

每次体验建议可在数分钟内完成。实际时长由儿童测试调整；不以失败扣资源，不让宠物生病、逃跑或因缺席受损。

## 2. 学习循环

- **呈现**：图像、英文、简短中文释义与可选音频。
- **练习**：由易到难使用识图选词、听音辨词、配对等题型。
- **反馈**：由团团以共同探索的口吻提供线索、正确答案、重听或再试机会；具体表达遵循 [团团角色设计规范](GAME_DESIGN.md)。
- **巩固**：记录知识点结果，按简单间隔规则安排复习；后续可用数据优化，但须可解释。
- **迁移**：把目标词放进短句、剧情或小游戏语境。

## 3. 团团与宠物系统

- 团团是孩子的智能陪伴伙伴，不是宠物或老师；它陪孩子探索，不命令孩子学习。角色表达以 [团团角色设计规范](GAME_DESIGN.md) 为准。
- 其他毛茸茸朋友可进入独立的宠物养成系统；其具体设定由美术和内容团队确认。
- 宠物亲密度可来自互动探索；答错不扣值，离开游戏不衰减。团团不使用喂养、驯养或好感度规则。
- 奖励以表情、装饰、合照/场景和对白为主，不影响题目公平性。
- 数值只服务可感知反馈；避免无限刷取、概率抽奖和付费随机物品。
- 状态可由事件确定性更新，设置上限并可重复展示已获得奖励。

## 4. 剧情系统

短章节由节点、对白、插图/音频和解锁条件组成。条件可引用完成单元、掌握知识点数量或完成指定小游戏；剧情不设置错题卡死门槛。关键文本短句化，英文出现时提供音频或中文辅助。分支初期以轻量选择呈现，不影响学习内容完整性。

## 5. 小游戏系统

统一接口：`start(level, itemPool)`、`presentQuestion()`、`submit(answer)`、`finish(summary)`。建议首期做“听音找伙伴/图片配词”一类低操作负担玩法。计分强调完成与练习，不公开排名；关卡结果写成通用 AnswerEvent/StudySession，避免小游戏私有的另一套掌握度。

## 6. 奖励与经济规则

- 完成学习目标得到固定的小奖励；高正确率可给鼓励信息，不额外制造稀缺资源压力。
- 重试仍可完成目标，奖励不因答错而被剥夺。
- 不设置体力门槛、付费捷径、限时错失、连续签到断档惩罚或玩家互比。
- 新内容主要随学习进展解锁；复习可重复得到积极反馈但避免无限兑换循环。

## 7. 难度与个性化

初期依赖年级/单元顺序和最近作答正确情况：连续困难则增加提示或回到图像/听音辨认，熟练后混合复习。规则透明、可调试；不推断儿童能力标签并对外展示。未来若使用推荐算法，应评估偏差、隐私与可解释性。

## 8. 无障碍、保护与验收

关键操作有文字标签；音频可重播并提供非音频替代；错误反馈避免羞辱性语言；支持暂停/退出并保留进度。试玩验收关注儿童是否理解目标、是否能独立操作、是否能从反馈中学会，而非只看停留时长。
