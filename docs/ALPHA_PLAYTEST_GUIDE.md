# Alpha 0.2 儿童试玩指南

## 测试目标

验证小学三年级儿童第一次接触《团团和它的毛茸茸朋友》时，是否愿意自主完成第一章，并在获得奖励、认识米米后表达继续体验的意愿。重点观察真实行为，不以答题正确率给孩子打分。

本次只试玩现有 Alpha 内容：原创测试故事、示例英语词和一款听音找图小游戏。尚未接入正式教材。后续教材 PDF、多年级和家长端需求，可记录为反馈，但不要在试玩时承诺已有这些功能。

## 准备与记录原则

1. 建议每次一名儿童、约 15～25 分钟；由监护人同意并在场。记录可用代号，不收集真实姓名、学校或联系方式。
2. 使用微信开发者工具或已配置有效 AppID 的真机。检查音量、网络、页面显示和可点击区域。正式观察以真机为准；开发者工具仅用于技术预检。
3. 每位新测试者使用独立、清空的本地试玩档案。清除数据会删除该设备的试玩进度，操作前确认当前记录已保存。欢迎状态另存于 `fluffy-town:welcome:v1`，游戏档案位于 `fluffy-town:local:v4`；若要复现首次欢迎，两者都需清除。
4. 主持人只说：“你可以自己看看这个小故事，想点哪里都可以。遇到不明白的地方，请直接说出来。”尽量不指路。若孩子停住约 30 秒，可问“你觉得接下来会发生什么？”；仍无法继续时再给最少提示，并记录提示发生的位置。
5. 不要求孩子背单词，不用对错评价其表现。记录孩子原话、点击和停顿；不要把主持人的推测写成孩子的回答。录屏、录音或拍照须另获监护人同意。

## 试玩流程与观察点

| 环节 | 让孩子自然操作 | 记录什么 |
| --- | --- | --- |
| 第一次打开 | 从首页开始 | 是否注意到欢迎卡；是否知道可以继续 |
| 首页欢迎 | 阅读或跳过团团对白 | 团团给人的感觉；是否理解首页“今日任务”和“下一步” |
| 团团互动 | 自由探索首页 | 是否主动点击团团；点击后的反应是否被注意到 |
| 第一章剧情 | 自主点“开始冒险”并阅读对白 | 是否找到入口；是否喜欢米米与星星饼干的故事；哪里停顿 |
| 小游戏 | 听音、选图，允许答错和重听 | 是否理解“听音找图”；能否找到播放与选择按钮；错误反馈是否让孩子愿意再试 |
| 奖励 | 完成三条线索并回到故事 | 是否看见 2 星及章节完成后的 5 星；是否理解奖励从哪里来 |
| 米米解锁 | 走完第五幕并查看伙伴页 | 是否知道米米加入；是否想和米米继续冒险 |

自然体验路径：**第一次打开 → 首页欢迎 → 团团互动 → 第一章剧情 → 小游戏 → 奖励 → 米米解锁**。孩子偏离路径时先观察，不急于纠正；需要提示才能继续则记录为卡点。

## 必记观察项

- **下一步操作**：每一环节能否在无提示下找到入口；记录停顿时长与提示次数。
- **角色互动**：是否主动点击团团；是否看见互动反馈；是否尝试与米米打招呼。
- **任务理解**：能否用自己的话说出“现在要做什么”；“今日任务”和故事线索是否混淆。
- **剧情兴趣**：哪些对白或角色引起反应；是否主动催促继续故事。
- **继续意愿**：结束时先问“如果还有一章，你想继续玩吗？为什么？”记录原话，再记录愿意／不确定／不愿意。不要诱导“想不想获得更多星星”。

每位测试者使用 [试玩反馈记录模板](PLAYTEST_FEEDBACK_TEMPLATE.md) 记录完成情况与关键原话。建议至少观察 5 位目标年龄儿童后再汇总重复出现的卡点；人数不足时仅报告个别观察，不推断整体儿童喜好。

## 技术预检与中断处理

试玩前按 `docs/ALPHA_TEST.md` 的流程完成一轮技术预检：欢迎、团团点击、故事、三轮小游戏、2 星、章节 5 星、米米解锁。进入第三幕、小游戏进行一半和完成后分别退出重进，确认游标与奖励保持。检查小游戏“继续故事”能返回故事、完成页能进入伙伴页或回树屋，手机系统返回也应可用。

若页面无法继续、存档消失或跳转到错误页面，立即停止该次流程，记录设备型号、基础库版本、所在页面、操作步骤、屏幕提示和是否能复现；不让孩子反复尝试修复。若只是音频无法播放，可记录音频问题并观察英文词退路是否让孩子继续。

## 本轮代码级预检结论

截至 Sprint 4-D，页面注册包含 `home`、`story`、`games`、`pets`；现有调用路径与返回入口可串成第一章闭环。本地模拟走查覆盖首次欢迎、团团互动、答错重试、小游戏中断恢复、章节完成、奖励及重进存档。未发现该模拟路径中的卡死、错误跳转、状态丢失或重复领奖。**微信开发者工具实际编译、系统返回手势、真机音频与儿童可用性仍待现场验证**；这份结论不代替真实试玩。
