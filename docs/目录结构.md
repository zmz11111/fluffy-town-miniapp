# 目录结构

以下为目标结构。Sprint 1 已创建 `miniprogram/` 的入口、首页、单词预览页及 `pets/`、`english/`、`storage/` 模块；其余目录在对应阶段创建。

```text
fluffy-town-miniapp/
├─ README.md
├─ project.config.json             # 微信开发者工具配置（创建小程序项目时补齐）
├─ project.private.config.json     # 本机配置，加入忽略规则
├─ docs/
│  ├─ 需求分析.md
│  ├─ 软件架构.md
│  ├─ 开发路线图.md
│  ├─ 目录结构.md
│  ├─ 技术选型.md
│  ├─ 数据库设计.md
│  └─ 游戏系统设计.md
├─ miniprogram/
│  ├─ app.js / app.json / app.wxss
│  ├─ pages/                        # 当前包含 index、learn
│  ├─ components/                   # 可复用展示组件
│  ├─ pets/                         # 团团资料与互动
│  ├─ english/                      # 示例词、学习记录与用例
│  ├─ storage/                      # 本地状态读写
│  ├─ content/                      # 后续教材内容包
│  └─ assets/                       # 后续已授权的图片、音频
├─ cloudfunctions/                  # 获批接入云开发后添加
├─ content-pipeline/                # 内容校验/导入工具后续添加
└─ .gitignore
```

约束：页面不直接读取数据库；内容包与代码分离；正式教材原件按授权和仓库策略单独存放，不默认提交；云函数只承载需可信执行的服务端逻辑。
