# 目录结构

以下为目标结构。Sprint 2 已注册 `home`、`learn`、`story`、`games`、`pets` 页面；`room` 和 `profile` 仍为未来规划。

```text
fluffy-town-miniapp/
├─ README.md
├─ project.config.json             # 微信开发者工具配置（创建小程序项目时补齐）
├─ project.private.config.json     # 本机配置，加入忽略规则
├─ docs/
│  ├─ 需求分析.md
│  ├─ 软件架构.md
│  ├─ 开发路线图.md
│  ├─ 目录结构.md
│  ├─ 技术选型.md
│  ├─ 数据库设计.md
│  └─ 游戏系统设计.md
├─ miniprogram/
│  ├─ app.js / app.json / app.wxss
│  ├─ pages/
│  │  ├─ home/                     # 当前首页
│  │  ├─ story/                    # 第一章剧情页
│  │  ├─ pets/                     # 团团与米米伙伴页
│  │  ├─ games/                    # 听音找图页
│  │  ├─ learn/                    # 当前示例词预览页
│  │  ├─ room/                     # 预留房间页
│  │  └─ profile/                  # 预留档案/家长入口
│  ├─ components/                   # 可复用展示组件
│  ├─ pets/                         # 团团、米米资料与互动
│  ├─ english/                      # 示例词、学习记录与用例
│  ├─ storage/                      # 本地状态读写
│  ├─ game/                         # 游戏状态结构与读写入口
│  ├─ story/                        # 第一章五幕与剧情管理器
│  ├─ games/find-cookie/            # 听音找图规则与题目
│  ├─ reward/                       # 星星、伙伴解锁与预留奖励
│  ├─ content/                      # 后续教材内容包
│  └─ assets/                       # 原创占位图与 CC0 测试录音
├─ cloudfunctions/                  # 获批接入云开发后添加
├─ content-pipeline/                # 内容校验/导入工具后续添加
└─ .gitignore
```

约束：页面不直接读取数据库；内容包与代码分离；正式教材原件按授权和仓库策略单独存放，不默认提交；云函数只承载需可信执行的服务端逻辑。
