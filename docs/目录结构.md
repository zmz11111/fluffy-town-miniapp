# 目录结构

以下为目标结构。Sprint 1.5 已将首页迁入 `pages/home/`；页面目录已统一规划，当前只有 `home` 和 `learn` 注册为可运行页面，其余目录暂为空占位。

```text
fluffy-town-miniapp/
├─ README.md
├─ project.config.json             # 微信开发者工具配置（创建小程序项目时补齐）
├─ project.private.config.json     # 本机配置，加入忽略规则
├─ docs/
│  ├─ 需求分析.md
│  ├─ 软件架构.md
│  ├─ 开发路线图.md
│  ├─ 目录结构.md
│  ├─ 技术选型.md
│  ├─ 数据库设计.md
│  └─ 游戏系统设计.md
├─ miniprogram/
│  ├─ app.js / app.json / app.wxss
│  ├─ pages/
│  │  ├─ home/                     # 当前首页
│  │  ├─ story/                    # 预留剧情页
│  │  ├─ pets/                     # 预留其他伙伴页
│  │  ├─ games/                    # 预留小游戏页
│  │  ├─ learn/                    # 当前示例词预览页
│  │  ├─ room/                     # 预留房间页
│  │  └─ profile/                  # 预留档案/家长入口
│  ├─ components/                   # 可复用展示组件
│  ├─ pets/                         # 团团资料与互动
│  ├─ english/                      # 示例词、学习记录与用例
│  ├─ storage/                      # 本地状态读写
│  ├─ game/                         # 游戏状态结构与读写入口
│  ├─ story/                        # 测试章节、场景与剧情管理器
│  ├─ reward/                       # 五类测试奖励与奖励管理器
│  ├─ content/                      # 后续教材内容包
│  └─ assets/                       # 后续已授权的图片、音频
├─ cloudfunctions/                  # 获批接入云开发后添加
├─ content-pipeline/                # 内容校验/导入工具后续添加
└─ .gitignore
```

约束：页面不直接读取数据库；内容包与代码分离；正式教材原件按授权和仓库策略单独存放，不默认提交；云函数只承载需可信执行的服务端逻辑。
