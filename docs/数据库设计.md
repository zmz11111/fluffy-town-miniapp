# 数据库与内容模型设计

本设计区分**发布内容**与**用户进度**。初期内容可由版本化 JSON 提供、进度存于本地；云数据库是后续适配，不代表当前已创建生产集合。

## 1. 标识与通用字段

实体使用稳定字符串 `id`，避免以数据库自动 ID 作为业务关联。可变内容含 `schemaVersion`、`contentVersion`；时间采用 ISO 8601 UTC。云端用户文档以服务端身份映射的内部 `profileId` 为分区，不接受客户端指定他人 ID。

## 2. 内容实体

| 实体 | 核心字段 | 关系/说明 |
|---|---|---|
| Course | id, title, locale, grade, textbookRef, version | 课程包含多个 Unit。 |
| Unit | id, courseId, order, title, objectives, unlockRule | 一个学习主题或教材单元。 |
| LearningItem | id, unitId, type, prompt, answer, hints, difficulty, tags | 词汇、句型或知识点；不把答案直接暴露于不可信客户端判分时需评估。 |
| MediaAsset | id, kind, uri, checksum, attribution, licenseRef | 图片/音频资源及版权来源。 |
| Question | id, itemIds, type, payload, solution, feedback, version | 练习题，可被学习会话和小游戏引用。 |
| StoryNode | id, chapterId, text, mediaIds, unlockRule, nextNodeIds | 剧情节点与解锁条件。 |
| GameLevel | id, gameType, itemPool, rules, rewardPolicy | 小游戏关卡配置。 |
| ContentRelease | id, version, status, sourceRefs, reviewer, releasedAt | 导入、校对、审核和发布记录。 |

教材来源元数据应包含书名/版本/出版社（若适用）、页码、授权状态、授权凭证引用、抽取方法、审校记录。避免把受版权保护的整本 PDF 直接放入客户端包。

## 3. 用户进度实体

| 实体 | 核心字段 | 说明 |
|---|---|---|
| LearnerProfile | profileId, createdAt, settings, schemaVersion | 最小化匿名档案；家长关联机制待隐私方案确定。 |
| ItemProgress | profileId, itemId, seenCount, correctCount, mastery, dueAt, updatedAt | 每个知识点掌握和复习状态。 |
| StudySession | sessionId, profileId, unitId, startedAt, completedAt, contentVersion | 一次学习会话摘要。 |
| AnswerEvent | eventId, sessionId, questionId, itemIds, result, answeredAt | 答题事件；默认不保存自由文本或语音原始数据。 |
| PetState | profileId, petId, affection, unlockedCosmetics, updatedAt | 非惩罚式互动状态，限制数值范围。 |
| StoryProgress | profileId, chapterId, nodeId, completedAt | 已解锁/完成的剧情节点。 |
| SyncState | profileId, lastSyncAt, pendingCursor, schemaVersion | 增量同步元数据，不作为学习事实来源。 |

## 4. 关系与索引建议

- `Course 1—N Unit`; `Unit 1—N LearningItem`; `Question N—N LearningItem`。
- 用户进度按 `(profileId, itemId)` 唯一；事件按 `eventId` 幂等去重。
- 云端常用索引：`profileId + updatedAt`、`profileId + dueAt`、`profileId + sessionId`。
- 内容按 `contentVersion + status` 查询；客户端只读取已发布版本。

## 5. 同步与冲突

进度先写本地并记录变更 ID，断网后重试。答题事件追加写入、以 `eventId` 去重；掌握度由事件或明确的版本化算法重新计算。宠物展示状态由可信奖励规则推导或校验，客户端不可凭任意数值增加。删除档案需删除或去标识关联记录并使待同步队列失效。设备时间不可信，云端时间戳由服务端生成。

## 6. 隐私与保留

默认只保留学习所需进度，不要求真实姓名、生日、定位、通讯录或社交账号。需在上线前确定家长同意、访问控制、导出/删除、备份清除和保留期限；云端记录不得写入可识别日志。原始语音默认不采集。

## 7. 内容导入示例

PDF 抽取形成候选 LearningItem/Question 后，保留 `sourceRef`、`page`、`extractionMethod`、`reviewStatus`。只有授权状态和人工审核均通过的 ContentRelease 能进入客户端分发。schema 迁移必须保留旧进度可读性。
