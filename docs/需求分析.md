# 需求分析

## 1. 产品概述

《团团和它的毛茸茸朋友》是面向小学三年级英语学习者的微信小程序。玩家与主角团团及毛茸茸伙伴一起生活、学习并探索故事世界。英语学习是核心价值，宠物养成、剧情和小游戏承担动机、反馈与复习作用。

## 2. 用户与使用情境

- **主要用户**：小学三年级学生，英语基础初级，阅读能力有限，常在家长陪同或允许下使用。
- **辅助用户**：家长，可协助选择学习目标、查看简明进展和管理数据授权。
- **内容维护者**：项目编辑/教师，整理词汇、句型、音频和关卡内容。

## 3. 产品原则

1. 学习目标清楚、单次时长短、反馈积极，不用惩罚机制制造焦虑。
2. 游戏奖励服务学习进度，不以随机付费、排行榜压力或连续签到损失驱动留存。
3. 核心学习路径在网络不稳定时尽量可用；云服务故障不得阻断已下载内容。
4. 内容分级、可读、可听，避免依赖复杂阅读和精细操作。
5. 儿童数据最少化、用途透明、访问受控，并在上线前核实适用法律法规与平台规则。

## 4. 范围

### 首期 MVP 建议

- 首页/章节地图与基础导航。
- 一个主题单元的词汇卡片、听辨或跟读入口、选择/配对练习。
- 学习结果反馈与简单复习队列。
- 团团状态与一个伙伴的非付费养成反馈。
- 一段短剧情，以学习节点解锁。
- 一种小游戏，复用统一题目/答题接口。
- 本地学习进度保存；云同步留接口，待隐私与账号方案确认后开启。

### 后续范围

- 更多教材单元和课程包；PDF 解析、内容审核与人工校订工作流。
- 多宠物、分支剧情、更多题型和离线包管理。
- 家长视图、跨设备同步、云端内容管理与数据导出/删除。

### 明确不在初始化阶段

完整功能开发、账号体系上线、真实教材批量导入、支付/广告、社交、生产云部署。

## 5. 功能需求

| ID | 能力 | 验收要点 |
|---|---|---|
| F-01 | 学习内容 | 内容按课程/单元/知识点组织，词条含英文、中文释义、音频引用、难度和来源/版权元数据。 |
| F-02 | 练习 | 选择、听辨、配对等题型可复用；每题有答案、提示和解释，答题结果可记录。 |
| F-03 | 复习 | 按掌握状态安排复习；算法可解释、可配置，错误后提供温和重试。 |
| F-04 | 宠物 | 学习行为可触发互动、外观或剧情奖励；不得让宠物因错题或缺席受伤/消失。 |
| F-05 | 剧情 | 剧情节点由章节进度解锁；文本可短句化，支持插图/音频资源引用。 |
| F-06 | 小游戏 | 游戏规则短、操作简单；每局练习与学习目标关联，成绩回写统一学习记录。 |
| F-07 | 进度 | 展示已学内容和近期进步，不将进度用于公开排名。 |
| F-08 | 教材导入 | 接受 PDF 作为来源，先提取候选文本/词条，经人工校验、版权确认和版本发布后进入内容库。 |
| F-09 | 云扩展 | 通过适配层封装认证、同步和内容读取；本地模式可独立运行。 |
| F-10 | 隐私与安全 | 不收集非必要身份信息；敏感配置不进入客户端；提供授权、撤回、删除方案。 |

## 6. 非功能需求

- **易用性**：单屏主要操作明确；按钮和触控区域适合儿童；避免长文本和复杂表单。
- **性能**：首屏轻量；图片/音频压缩并按需加载；弱网和请求失败有可理解提示。
- **可靠性**：关键进度先本地写入；同步冲突有确定规则；所有内容有 schema 与版本。
- **可维护性**：业务领域分层，题型和内容由数据驱动；逻辑可独立于微信云端运行。
- **可访问性**：关键音频之外同时提供文字提示；颜色不作为唯一状态信号；支持静音情境。
- **安全/隐私**：最小权限、服务端鉴权、输入校验、日志脱敏、明确数据保留期限。

## 7. 待确认问题与风险

- “小学三年级英语”对应地区、教材版本、学期和课程标准尚未指定。
- 教材 PDF 的授权、扫描质量、内容版权及音频来源需逐项确认。
- 目标用户年龄涉及监护人同意、隐私告知和平台要求；上线前需专业合规审查。
- 微信小程序具体基础库、音频能力、云开发方案和成本需在项目创建时核验。
- 儿童语音采集默认不纳入 MVP；若未来加入，需单独评估同意、存储和删除机制。
