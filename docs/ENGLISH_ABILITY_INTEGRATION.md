# 教材知识—英语能力—游戏任务融合模型（Sprint 5-C 设计）

> 状态：设计稿，待审核。本文修正 Sprint 5-C 的方向：教材知识库不止用于审核与归档，还要经过明确的英语能力目标映射，成为有学习依据的任务和故事输入。本文只定义设计，不修改代码、不启用现有候选映射，也不生成正式剧情。
>
> 相关基线：[MVP 产品蓝图](MVP_PRODUCT_BLUEPRINT.md)、[学习系统设计](LEARNING_SYSTEM_DESIGN.md)、[教材接入计划](TEXTBOOK_INTEGRATION_PLAN.md)、[教材到游戏流程](CURRICULUM_GAME_PIPELINE.md)。

## 1. 设计目标与核心关系

每个 Unit 的内容设计都应能回答三个问题：

1. **孩子接触什么知识？** 具体到已确认教材版本、单元、词汇、句型或教学目标。
2. **孩子练习什么英语能力？** 说明孩子在听、说、读或情境中能够做出的可观察行为。
3. **孩子在游戏里做什么？** 将能力目标落实为适龄、可理解、可重试的任务，并说明完成证据。

核心链路：

```text
经确认来源的教材知识
        ↓ 知识点与单元目标
英语能力目标（本单元具体练什么）
        ↓ 任务类型、提示和完成证据
教材任务／故事输入／复习任务
        ↓ 在核心学习目标得到练习后
可选的课外拓展任务
```

三层职责保持分开：

| 层 | 回答的问题 | 内容示例 | 不负责什么 |
|---|---|---|---|
| 教材知识层 | 教材里有什么、出处在哪里？ | 词条、义项、句型、单元教学目标、来源页码 | 不判断儿童已掌握；不直接决定玩法或奖励。 |
| 能力目标层 | 孩子应能用这些知识完成什么？ | 听辨问候、在熟悉情境中理解简短表达 | 不复制教材整段活动；不作为一次答题的成绩。 |
| 游戏任务层 | 孩子当前要做什么、如何获得帮助？ | 听后选择线索、为情境选择合适表达、回顾旧词 | 不扩写教材内容；不擅自把候选内容设为正式剧情或运行时题目。 |

稳定引用使用“教材版本／内容版本 + Unit + 知识点 ID + 能力 ID + 任务 ID”。相同英文拼写不代表同一知识点；Welcome 先修词、不同年级义项和不同教材版本必须保留各自归属。映射可以多对多，但每条关系都要说明理由和审核状态。

## 2. 五类英语能力及其可观察证据

本项目首期使用以下五类能力标签。它们用于规划学习机会，不表示孩子能力总分，也不等同于一次答对率。

| 能力 | 三年级初学者可观察行为 | 可选任务表现 | 设计边界 |
|---|---|---|---|
| **听力理解** | 听一遍或多遍后，从少量熟悉线索中辨认词、人物意图或短句大意。 | 听音找词／图／情境；听短对话后选择下一步线索。 | 可重播；音频失败或静音时提供文字、图片等替代，不因设备问题记为失败。 |
| **词汇应用** | 在熟悉情境里认出词义，并把已学词与对象、人物或行动联系起来。 | 词义配对、情境选词、把已学词放入简单信息卡。 | 不把孤立记忆题称为真实交流；多义词按具体义项 ID 出题。 |
| **句型表达** | 理解短句用途；在示范和支持下选用、补全或排列合适表达。 | 选择一句适合当前情境的话、替换一个已学词、词块排序。 | 先有范例；自由造句不是起步门槛；口头表达可自愿，不采集语音作为默认证据。 |
| **阅读理解** | 从短词、短句或简短原创信息中找到显性信息，并与图片或人物对应。 | 找名字／关系／已学信息、读短提示选择物品。 | 限制阅读量和陌生词；不因阅读速度或识字差异作负面评价。 |
| **情境交流** | 根据说话对象和正在发生的事情理解或选择合适表达，并理解回应的作用。 | 在新朋友见面、互相帮助等原创场景中选择回应或下一步。 | 不把礼貌、外向程度或现实社交表现打分；错误反馈聚焦语言线索和情境。 |

### 能力练习阶段

策划时可以用以下顺序描述任务提供的练习机会，不能据此自动宣布掌握：

1. **接触与辨认**：看到、听到或读到知识点，完成一次识别。
2. **有支持的应用**：在熟悉情境中使用知识点；可以重听、看示范或获取提示。
3. **迁移尝试**：在原创、稍有变化的情境中再次使用相同或已确认相关的知识。

同一能力应尽量在不同任务或不同时间再次观察。单次完成只记作这次任务的完成证据，不写成“已掌握”或长期能力结论。

## 3. 课本核心内容与课外能力拓展

### 3.1 课本核心内容（`textbook_core`）

满足以下条件的内容，才可列为对应教材 Unit 的核心：

- 能追溯到已确认教材版本和该 Unit 的学生教材、教师用书或单词表来源；
- 明确记录 PDF 页码、书内页码（如有）和原文位置；
- 经英语、教学适龄性、单元归属和使用权审核；
- 能关联本单元教学目标或明确标记为教师确认的基础知识。

核心内容决定该 Unit 的**必需学习覆盖**：孩子有机会认识、理解并练习这些已选目标知识。它不要求把教材每一页照搬进游戏，也不要求儿童一次正确完成。游戏可用原创场景承载练习，但语言事实和学习目标须与已审核核心内容一致。

Welcome 或前一单元学过、但在本单元词表中不属于正式词条的内容，应标为 `prerequisite`，按前置知识引用。它可以帮助理解核心任务，但不得为了方便而改归到本 Unit 的核心词表。例如，Unit 1 中再次出现的问候语若归属 Welcome，应保留先修关系和各自来源。

### 3.2 课外能力拓展（`extension`）

拓展内容用于把已学知识迁移到新情境、增加一种表达机会或连接已学旧知识。拓展任务必须：

- 明确标记为可选拓展，不计入课本核心覆盖完成条件；
- 注明新增的词句或情境来自原创内容、另一份经核验资料，或经授权资源；
- 若加入课本之外的新语言内容，单独登记来源／作者、年级适配、审核和授权状态；
- 以核心知识为支点，提供示范、提示和退出方式；不能因孩子没做拓展而失去剧情进度或已获得的核心奖励；
- 不用未审核拓展内容测试核心目标，也不把拓展表现混入教材核心掌握判断。

“课外”不等于可随意生成或免于审校。未经来源核验、英语审校和使用权确认的外部材料，不能作为可发布拓展内容。原创拓展情境也要经过年龄、隐私和角色语气检查。

### 3.3 两类内容的关系

```text
课本核心：确定本 Unit 的必需学习目标与最低任务覆盖
    ├─ 有示范的核心练习
    ├─ 核心故事输入（解释当前学习行动的意义）
    └─ 核心复习（再次遇到同一知识点）
             ↓ 核心目标已得到支持和练习后
课外拓展：可选的迁移、组合或新情境练习
```

核心与拓展使用不同内容标签、任务 ID 和完成状态。孩子可先完成任一核心任务；若尚不熟悉，可重听、看提示或稍后返回核心任务。拓展不设时间压力、排行榜或失败惩罚。

## 4. 每个 Unit 的四类任务内容包

每个 Unit 经审核后规划四类输出。这里的“生成”指由内容负责人依照模板编排内容候选，不是从 PDF 自动生成正式剧情或直接写入游戏。

| 内容类别 | 主要职责 | 必备引用与字段 | Unit 结束前的最低要求 |
|---|---|---|---|
| **教材任务** | 覆盖已批准的核心知识和能力目标。拆成短任务，每项聚焦少量知识点。 | `taskId`、`unitId`、知识点 ID、能力 ID、`textbook_core`、目标行为、儿童提示、操作、完成证据、来源指针、审核状态。 | 每项核心教学目标至少有一个适龄练习机会；重要知识点不得只出现在说明文案中。 |
| **拓展任务** | 让孩子在不同的原创情境中尝试迁移核心知识，或连接已学内容。 | 除任务字段外，还要有 `extension`、新增语言点清单、内容来源／原创声明、适龄与权利状态、可选标记。 | 每个 Unit 可没有拓展；有拓展时必须可跳过，且不增加核心目标负担。 |
| **故事输入** | 给剧情／场景编写者说明学习目标为什么出现在当前冒险里，提供角色状态、情境线索和任务触发意图。 | `storyInputId`、核心／拓展关联、关联知识点与能力、场景意图、角色互动意图、需避免的语言和表现、来源 ID。 | 至少给核心任务提供简短、儿童可理解的情境理由；保持为创作简报，经过单独审稿后才形成正式对白或剧情。 |
| **复习任务** | 在后续环节或 Unit 中重新遇到旧知识，观察能否回想或迁移。 | `reviewTaskId`、原知识点与版本、原能力 ID、复习间隔／触发依据、对比新情境、提示阶梯、复习完成证据。 | 复习保留原知识归属，不重复计作新授；允许提示后完成，不因遗忘扣奖励。 |

### 四类内容的先后安排

1. **先列核心**：按经审校的教学目标和知识点列出核心任务，不先从玩法反推课程内容。
2. **再配故事输入**：只解释孩子当前共同探索的目标，不让角色用说教方式讲教材。
3. **安排复习**：选择本 Unit 核心知识或经确认的先修知识，标清复习而非新授。
4. **最后考虑拓展**：先确认核心练习有足够提示和重试，再决定是否需要可选拓展。

不是每个词都需要单独做成一关。一个任务可以覆盖多个相互关联的知识点，但必须能说清每个知识点练到什么能力、儿童要做什么；不得为了填满任务数量而重复刷题。

## 5. Unit 1 规划示例（只说明映射，不替代审核）

以下示例说明如何应用模型，不是 Unit 1 的正式内容包。当前 Unit 1 导入资料和游戏候选仍为待人工审核；示例中提到的实际知识点必须先核对其稳定 ID、来源和审核状态。

| 计划项 | 知识 → 能力 | 任务／内容意图 | 分类与证据 |
|---|---|---|---|
| 核心听辨练习 | Unit 1 中经确认的问候／介绍知识 → 听力理解、情境交流 | 听原创角色的简短交流，找出当前发生的互动或适合的下一步。提供重听和文字辅助。 | `textbook_core`；完成一次声音／情境匹配；不以一次成功推断已掌握。 |
| 核心短句练习 | 已审核句型 → 句型表达、阅读理解 | 看示范后，为原创人物关系或对话场景选择／组合合适短句。 | `textbook_core`；记录使用的知识点、是否看过提示及本次选择。 |
| 可选迁移练习 | 相同核心知识 → 词汇应用、情境交流 | 在新的原创场景中再次使用已学表达；如果需要引入新词，先单独登记并审校。 | `extension`；可跳过，完成不影响核心奖励或主线通行。 |
| 故事输入简报 | 核心交友／互助目标 → 情境交流 | 说明角色刚遇见新伙伴，需要孩子观察线索并帮助继续共同探索；只给场景目的，不写正式剧情对白。 | 核心故事输入；正式故事仍需独立创作与审核。 |
| 间隔复习 | 已完成的 Unit 1 知识点 → 原能力目标 | 在后续场景中再次听、读或选择同一知识点，逐步减少默认提示；答错时可恢复提示。 | `review`；沿用原词条／句型 ID 和教材版本，标记“再次练习”。 |

Welcome 先修词须通过独立 ID 与关系引用。不能将它们重复计入 Unit 1 的正式词汇总数；若 Unit 1 核心练习需要它们，应明确标记为“先修支持”，并保证主目标仍在 Unit 1 核心知识上。

## 6. 能力映射与任务记录建议

映射关系应便于未来多教材、多年级与家长端摘要读取，至少保存以下概念字段；本节是数据设计建议，不代表现在新增代码或变更存档：

- **适用范围**：`textbookId`、内容版本、年级、册别、`unitId`。
- **来源知识**：稳定知识点 ID、词条义项或句型 ID、`sourcePointer`、知识范围标签（核心／先修／拓展）。
- **能力目标**：能力 ID、预期儿童可观察行为、与知识点的映射理由、审核状态。
- **任务定义**：稳定任务 ID、教材任务／拓展／故事输入／复习类型、交互形式、核心／可选属性。
- **教学支持**：儿童提示、示范、重听／重看、提示阶梯和跳过方式。
- **完成证据**：本次完成行为、知识点引用、能力目标引用、支持程度；不能直接存成永久“已掌握”。
- **发布状态**：来源审核、英语与教学审核、素材权利和儿童隐私检查状态。

未来学习记录建议只保存完成能力回顾所需的最小摘要，例如“接触过／完成练习／在不同情境尝试”及使用的提示级别。默认不保存原始口语录音、自由输入全文或不必要的儿童身份信息。家长端若后续获批，可显示教材来源、核心目标练习经历和可继续学习的内容，不展示未经验证的能力分数。

## 7. 课本掌握优先的编排规则

1. **先覆盖，再拓展**：核心知识点要有对应的学习机会；拓展不能代替核心任务。
2. **核心目标不被剧情门槛挤压**：若剧情需要某个完成条件，应基于有示范、有提示、可重试的核心练习；不得要求儿童掌握课外内容才能继续。
3. **难度逐步增加**：先听／看示范，再做支持下练习，最后才提供可选迁移尝试。阅读量、陌生词数量和选项数量均须按三年级初学者审核。
4. **答错不扣减**：可重播、重看、提示、跳过或稍后返回；奖励和伙伴关系不因答错、退出或没做拓展而减少。
5. **能力结论需要多次证据**：同一知识点的再次遇见可换情境，但应保留原知识 ID；一次选对不是掌握证明，一次答错也不是能力不足结论。
6. **内容缺失要明示**：缺少音频、图片、来源页码或授权时，降低到可支持的交互或暂缓发布，不假装资源存在。
7. **拓展保持可选**：扩展提供新的应用体验，不以更难、更快或更高分吸引儿童，也不制造错失奖励压力。

## 8. 内容评审与发布门槛

每个 Unit 交付评审时检查：

- [ ] 教材版本、Unit 边界、词条归属及来源位置已核实；Welcome／Appendices 等范围未混入错误单元。
- [ ] 每个核心教学目标至少映射到一个能力目标和一项可观察练习；未被任务覆盖的目标已说明原因。
- [ ] 每项能力映射都引用具体知识点 ID，并说明关系是直接练习、先修支持还是迁移。
- [ ] 核心任务具备示范／提示／重试和清楚的完成证据；不将探索行为误记为长期掌握。
- [ ] 拓展内容独立标记来源和审核状态，确认可跳过，不成为剧情或奖励的必要门槛。
- [ ] 故事输入仍是创作简报；语言、角色对白和剧情经过单独原创与审核，没有自动发布教材原文。
- [ ] 复习关联原内容版本和能力目标，不篡改 Welcome／Unit 归属，也不重复发新授奖励。
- [ ] 素材来源／授权、目标年龄、隐私和家长端将来可能展示的信息已经过对应评审。
- [ ] Unit 内容包未审核通过前标记为候选／待审核，不被小程序运行时读取。

建议发布状态按“来源已核验 → 内容与教学已审核 → 任务与资源已审核 → 发布批准”推进。某项任一关未通过，就保持该项待处理；不得因 JSON 结构有效或来源位置已核对而把它提升为正式学习内容。

## 9. 本设计不包含的工作

- 不改动小程序代码、存档、学习记录、剧情、游戏或奖励系统。
- 不把 Sprint 5-B 的待审核 Unit 1 内容直接接入运行时，也不将其状态提升为已批准。
- 不创作或发布正式剧情、题目、音频、图片或教材衍生材料。
- 不宣称某一 Unit 的孩子已达到能力标准；能力描述只服务内容设计和学习机会规划。
- 不自动生成教材、拓展内容或儿童能力结论。

**本阶段验收结果**：形成一套可以逐 Unit 复用的融合规则，使教材核心知识优先转成能力练习，再以可选拓展支持迁移，并让故事和复习围绕同一组可追溯知识点服务学习。具体 Unit 内容仍须单独审核后才能进入开发。
