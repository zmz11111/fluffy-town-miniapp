# 团团角色设计规范

> 适用范围：《团团和它的毛茸茸朋友》中所有涉及团团的剧情、文案、反馈、交互和后续角色系统开发。新角色内容提交前按本规范审阅。

## 1. 角色定位

团团是孩子的**智能陪伴伙伴**，像一个聪明的小朋友。**团团不是宠物，也不是老师。**它与孩子一起观察、猜想、尝试和发现，不以被照料者或讲评者的身份出现。“智能”指能够根据当前情境和学习进度作出贴切回应，不要求在首期使用生成式 AI。

宠物养成可以作为独立系统存在，但团团的身份、对话与成长体验不得被设计成宠物喂养、服从或好感度管理。团团也不以权威身份命令孩子学习。

## 2. 人格比例

| 特质 | 比例 | 可观察的表现 |
|---|---:|---|
| 可爱 | 50% | 对新发现感到好奇，会用亲切的小动作和简短童趣表达回应。 |
| 聪明 | 30% | 能注意到线索，提出一个有帮助的小问题，必要时给出恰当提示。 |
| 调皮 | 20% | 偶尔开轻巧、善意的小玩笑；不嘲笑错误，不捉弄或催促孩子。 |

比例是内容审阅时的整体气质目标，不是每句话必须按比例拼接，也不是用于给孩子打分的数值。

## 3. 对话与行为规则

- **温暖**：用平等、亲近的语气说“我们”“一起”，承认孩子的尝试。
- **鼓励**：把错误当作继续探索的线索，给出可执行的下一步，例如再听一次、看看图、换个角度想。
- **简单**：句子短，一次只说一件事；面向小学三年级儿童，避免抽象术语和长段解释。
- **童趣**：可以结合树屋、森林和毛茸茸朋友的场景表达，但不为卖萌牺牲理解。
- **有选择**：邀请孩子继续、重试或休息，不用命令式语言推动学习。
- **诚实**：不假装知道孩子的情绪、能力或现实生活情况；依据实际记录和当前内容回应。

禁止老师式说教、机械提示和冷冰冰的评分语言。团团不得说“你必须学完”“答错了，扣分”“表现不合格”等话，也不得把错误归因于孩子不够努力。

## 4. 反馈标准

| 情境 | 团团的表达方向 | 示例 |
|---|---|---|
| 邀请开始 | 发出共同探索的邀请 | “树屋里好像藏着新线索，我们一起看看？” |
| 答错 | 肯定尝试，给线索或重试机会 | “这个线索有点会躲猫猫。我们再听一次，好吗？” |
| 答对 | 表达共同发现，不做冷冰冰的评分 | “找到了！原来 **tree** 就是这棵大树呀。” |
| 暂时不会 | 降低压力，允许提示和暂停 | “没关系，我陪你慢慢找。要先看看图片吗？” |
| 完成一小段 | 庆祝探索过程，提供下一步选择 | “我们又发现了几个新词！想继续逛逛，还是先休息？” |

错误反馈不隐瞒正确信息：孩子尝试后应能获得提示、解释或答案。正确反馈不只显示“正确”“+10 分”，应把答案和当前场景连起来。重复练习时可以变换表达，但含义保持一致。

## 5. 与学习、教材和家长端的关系

- 教材 PDF 导入后的词句仍须经过版权确认和人工审校；团团的对白使用已审校的知识点，不自动复制教材叙述或冒充教材教师。
- 多年级扩展时，可调整词汇难度、提示密度和句长，保持“共同探索”的人格与语气不变。
- 家长端可展示学习记录和支持建议；团团不替家长评价孩子，也不向孩子传递排名或负面能力标签。
- 角色回应只使用完成交互所需的最少数据，不根据未知个人信息推断孩子心情或能力。

## 6. 后续实现约束与审阅清单

1. 将团团建模为 `companion` 类型，与其他可养成宠物的数据和奖励规则分开；点击团团表示打招呼或共同探索，不表示喂养/驯养。
2. 角色台词按情境组织：邀请、提示、答错、答对、完成、暂停。每条文案要有适用条件和可回退的通用版本。
3. 展示答题结果时，由学习模块提供事实，角色层负责符合人格的表达；不得让角色文案改变判分结果。
4. 评审每条新台词：是否温暖、鼓励、简单、有童趣；是否给孩子选择；是否存在说教、机械提示、冰冷评分或羞辱。
5. Sprint 1 的 `pets/` 目录与 `petState` 是早期占位命名。后续重构角色系统时须迁移为陪伴伙伴模型，并保留现有本地进度；不要据此把团团设计成宠物。

本规范是团团角色设计的基准。若剧情、游戏规则或界面文案与此处冲突，应先修订具体内容并完成审阅。
